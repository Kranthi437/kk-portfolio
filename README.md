# Kranthi Kumar — Editorial Portfolio (8+ Years)

This is the single Editorial Light portfolio design, based on the 8+ years resume supplied by Kranthi Kumar.

## Files
- `index.html` — complete portfolio page (CSS and JavaScript are embedded; no styles or scripts folders needed)
- `kranthi-kumar-profile.png` — portfolio portrait
- `Kranthi-Kumar-8-Years-Resume.docx` — downloadable 8+ years resume

## Upload to GitHub
Upload these three files directly to the repository root. No folders are required. Do not upload the ZIP itself.

## Deploy on Vercel
Import the GitHub repository in Vercel. Use Framework Preset `Other`, leave Build Command and Output Directory blank, and set Root Directory to `./`.

The root URL will serve `index.html`.
